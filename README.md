# kyoangel/homebrew-tap

Homebrew tap for tools by [kyoangel](https://github.com/kyoangel).

```sh
brew tap kyoangel/tap
brew trust kyoangel/tap
```

## Apps

| Name | Install | |
|------|---------|---|
| [MemLens](https://github.com/kyoangel/memlens) | `brew install --cask kyoangel/tap/memlens` | macOS menu bar memory monitor for people running local AI models |
